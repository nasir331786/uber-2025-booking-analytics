# Uber 2025 Booking Analytics

> Explore booking trends, key performance indicators, revenue, and operational insights.


## 📊 Project Overview

This project presents an interactive Power BI dashboard designed to analyze Uber booking data for 2025. The dashboard transforms raw booking data into meaningful KPIs, trends, and business insights to support data-driven decision-making.

## 🎯 Business Objective

The objective of this project is to analyze Uber booking performance and identify important trends across bookings, revenue, trip activity, customer behavior, and operational performance.

## 📌 Key KPIs

- Total bookings
- Revenue / booking value
- Trip and ride performance
- Operational metrics
- Time-based booking trends

> KPI definitions correspond to the fields and visuals used in the Power BI report.

## 📈 Dashboard Features

- Booking performance analysis
- Revenue analysis
- Ride/trip trend analysis
- Operational performance metrics
- Time-based trend analysis for 2025
- Interactive filters and slicers for KPI monitoring
